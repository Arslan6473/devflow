# DevFlow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build DevFlow — a premium, fully client-side developer tools platform (5 tools) with a polished SaaS UI, MDX blog/docs, and strong SEO.

**Architecture:** Next.js 15 App Router with a registry-driven tool model (`config/tools.ts` is the single source of truth driving pages, search, SEO, sitemap). Pure tool logic lives in `lib/` (unit-tested with Vitest) and is consumed by thin React tool components. Client-only state (favorites/recent) uses persisted zustand stores.

**Tech Stack:** Next.js 15, TypeScript (strict), Tailwind CSS v4, shadcn/ui, Framer Motion, next-themes, zustand, sonner, lucide-react, @monaco-editor/react, jose, react-hook-form, zod, MDX, Vitest.

## Global Constraints

- Next.js 15 App Router only (no Pages Router).
- All tool processing is 100% client-side — no input is ever transmitted.
- Tailwind CSS v4 (CSS-first config; theme tokens as CSS variables in `globals.css`).
- Dark mode is the default theme; light mode available via next-themes.
- Tool logic in `lib/` returns discriminated results `{ ok: true, value } | { ok: false, error: string }` — never throws across the UI boundary.
- Monaco and other client-only components are dynamically imported with `ssr: false`.
- All dependencies must be open-source.
- TypeScript strict mode; `next build`, `tsc --noEmit`, and `eslint` must pass at the end.
- Project root: `/home/hp/Projects/Test-Project/devflow`.

  ```ts

  const parse = (input: string): Result<unknown> => {
    try { return ok(JSON.parse(input)); }
    catch (e) { return err(e instanceof Error ? e.message : "Invalid JSON"); }
  };
  export function formatJson(input: string, indent: number | "\t" = 2): Result<string> {
    const p = parse(input);
    return p.ok ? ok(JSON.stringify(p.value, null, indent)) : p;
  }
  export function minifyJson(input: string): Result<string> {
    const p = parse(input);
    return p.ok ? ok(JSON.stringify(p.value)) : p;
  }
  export function validateJson(input: string): Result<true> {
    const p = parse(input);
    return p.ok ? ok(true) : p;
  }
  ```
