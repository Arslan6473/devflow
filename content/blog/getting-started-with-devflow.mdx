# Getting Started with DevFlow

DevFlow is a collection of free, browser-based developer tools built for speed, privacy, and convenience. Every tool runs **entirely in your browser** — nothing you paste is ever sent to a server or stored anywhere.

## Why DevFlow?

Modern developers spend a surprising amount of time on repetitive tasks: formatting JSON payloads, decoding JWT tokens, checking regex patterns. DevFlow solves this by putting all your essential tools in one fast, keyboard-friendly interface.

## The Tools

### [JSON Formatter](/tools/json-formatter)

Paste raw or minified JSON and instantly see it formatted with proper indentation and syntax highlighting. Validation errors are caught in real-time. Great for debugging API responses or cleaning up config files.

### [JWT Decoder](/tools/jwt-decoder)

Decode JSON Web Tokens directly in your browser. DevFlow shows you the header, payload, and signature without ever sending the token to a server — critical for tokens that may contain sensitive claims.

### [Base64 Encoder & Decoder](/tools/base64)

Encode text or binary data to Base64, or decode Base64 back to plain text. Useful for email attachments, data URLs, and working with APIs that use Base64 encoding.

### [URL Encoder & Decoder](/tools/url-encoder)

Encode strings for safe inclusion in URLs, or decode percent-encoded strings back to their original form. Handles both `encodeURIComponent` and `encodeURI` semantics.

### [Regex Tester](/tools/regex-tester)

Write and test regular expressions with live match highlighting. See all match groups, test flags (`g`, `i`, `m`, `s`), and iterate quickly without switching between editor and terminal.

## Keyboard Shortcuts

DevFlow is designed for keyboard-first use:

- Press **⌘K** (or **Ctrl+K** on Windows/Linux) to open the command palette
- Press **/** anywhere outside an input to jump straight to search
- Each tool page has its own keyboard shortcuts shown in the UI

## Getting the Most Out of DevFlow

1. **Bookmark the tool you use most** — each tool has its own URL so you can jump straight to it.
2. **Use the command palette** — ⌘K lets you switch between tools without reaching for the mouse.
3. **It works offline** — once the page has loaded, the tools work without an internet connection.
4. **No account required** — there is nothing to sign up for. Open a tool and start working.
