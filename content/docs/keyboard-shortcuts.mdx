# Keyboard Shortcuts

DevFlow is designed for keyboard-first use. This page lists every shortcut available across the application.

## Global Shortcuts

These shortcuts work from any page in DevFlow.

| Shortcut | Action |
|----------|--------|
| `⌘K` / `Ctrl+K` | Open the command palette |
| `/` | Focus the search input (when not in a text field) |
| `Escape` | Close the command palette or dismiss a modal |

## Command Palette

Press **⌘K** or **Ctrl+K** to open the command palette. Once open:

| Shortcut | Action |
|----------|--------|
| `↑` / `↓` | Move through results |
| `Enter` | Navigate to the selected item |
| `Escape` | Close the palette |
| Type to filter | Narrows results by tool name or action |

### What you can do from the command palette

- Navigate to any tool by name (e.g., type "jwt" to jump to the JWT decoder)
- Navigate to Docs, Blog, About, or Contact
- Toggle between light and dark mode

## Tool Pages

Within an individual tool page, the following shortcuts apply:

| Shortcut | Action |
|----------|--------|
| `⌘Enter` / `Ctrl+Enter` | Process / run (where applicable) |
| `⌘A` / `Ctrl+A` | Select all text in the active input |
| `⌘C` / `Ctrl+C` | Copy selected text |

Each tool may have additional shortcuts — look for shortcut hints in the tool interface.

## Tips

- **Quick tool switch**: Open the command palette and type the tool name. Press Enter. You rarely need to reach for the mouse.
- **Search from anywhere**: Press `/` on any page to immediately start searching for a tool. This works from the homepage, blog posts, and docs pages alike.
- **Keyboard nav in results**: After pressing `/` or `⌘K`, the arrow keys move through suggestions without leaving the keyboard.

## Accessibility

All interactive elements in DevFlow support keyboard navigation. You can tab through the interface normally, and focus indicators are visible at all times.

If you encounter a keyboard accessibility issue, please [contact us](/contact).
